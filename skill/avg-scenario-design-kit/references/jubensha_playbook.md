# 剧本杀企业培训：设计 → 交付 → 运营方法论

> 来源：国内真实"课程→剧本杀/沉浸式情景"企业培训赛道（相邻竞品、真实产出物）。
> 目的：本平台最终产出物是**与竞品一样的线下产品包**，因此必须吃透"剧本杀是怎么设计、交付、运营的"。
> 关键认知：剧本杀培训 ≠ 娱乐剧本杀。它的灵魂是**复盘（Debrief）**，没有结构化复盘的剧本杀只是团建。

## 1. 为什么参考剧本杀（相邻真实赛道）

- 国内**没有"课程→AVG"软件平台**，但**有"课程→剧本杀"的产出物赛道**，抢同一块培训预算、同一类学习目标（角色扮演 + 复盘）。
- 真实案例：邮储《阳光之下》廉洁剧本杀、农行《清风廉影》、兴业银行《大岭山之歌》红色剧本杀、工行《铁路大厂》党建剧本杀、《星际启航》（新员工职业素养）、《列车藏宝》（问题分析与解决）、《职场局中局》（管理者技能）、《冰川之下》（目标计划）、《陆拾公园迷案》（服务营销）。
- 它的痛点 = 我们的机会：单门课生产 **1–3 个月**、定制 **¥5K–50K/套 + 现场 DM**、**无数据回流**、**难多人分组同屏**。本平台把"单门课 AVG 化"压到**小时级 / 订阅摊薄**。

## 2. 线下产品包组件清单（离线包该有什么）

剧本杀培训的可带走产出，是一整套**实体教学材料**。本平台离线包应对齐：

| 组件 | 说明 | 平台对应 |
| --- | --- | --- |
| 剧本本（主线 + 分支） | 故事、情节、分支逻辑 | Course→AVG 转换产物 |
| 角色卡 | 每组/每人扮演的角色、目标、秘密、背景 | Role 工作区 |
| 线索卡 / 物证 | 探索阶段搜集的证据 | Exploration 产物 |
| 道具 / 物料 | 实体信物、计时沙漏、投票贴 | 离线包素材 |
| **DM 手册（主持人手册）** | 控场流程、时间线、分支指引、追问话术 | Facilitator Console 导出 |
| **复盘手册 / 知识卡片** | 复盘引导、理论点、产出模板 | Reflection 产物 |
| 计分 / 投票工具 | 抉择记录、小组对比 | Decision/Consequence |
| **产出物模板** | 能力雷达图、行动计划、共识制度 | 可带走成果 |

> 红线：本平台离线包必须**内嵌可带走的成果模板**（能力雷达图/行动计划/共识制度）。
> 否则学员"玩得开心但业务不变"——这是剧本杀培训被诟病的核心风险，也是我们碾压它的抓手。

## 3. 设计流程（选题 → 上线）

1. **根据课程主题定剧本杀主题**
2. **根据课程目的确定剧本类型**（推理/情感/经营/红色…）
3. **根据授课人群确定角色**（角色要让人"找到定位"）
4. **根据授课内容设定故事大纲**
5. **根据角色工作设定角色故事**
6. **根据培训目的/预期设计结局与评分**（阶梯式评分：不同选项赋予不同成长值；干扰项设计为"看似合理但非最优"）
7. **剧本创作 → 道具设计 → 体验流程设计 → 测试与上线**

设计理念范例（吴婷）：**"先成剧中人，再悟剧中意"** + "演、练、学、化"四步教学法。

## 4. 现场交付流程（典型 1 天 / 6 小时，或五幕结构）

```
开幕剧 + 剧情介绍
  → 阅读剧本（读本）
    → 角色自我介绍（建立角色认同）
      → 第一轮线索搜查
        → 第一轮讨论
          → 第一轮投票
            → 第二轮线索搜查与讨论
              → 第二轮投票
                → 真相揭示
                  → 【复盘】（灵魂环节）
```

- 线上版常做"一幕深度体验"；线下规划"五幕主线 + 2–3 幕替补剧目"，按企业性质/学员情况灵活抽选（应对关键学员缺席或强化某主题）。
- 角色认同技巧：让学员**用剧中名字互相称呼**——"当学员用剧中名字称呼彼此时，角色认同自然产生，他们不是来听课，是来履职"。

## 5. 引导技术（Facilitation / DM 技术）

- **教练式提问（"为什么？"）**：学员分享决策后，不表面认可，而是深挖背后的思考过程。"问题问得很深，尤其回答后追问，建立了与课程的信任感。"把管理者从"完成任务"拉向"反思过程"。
- **知识卡片动态匹配**：理论点（如 4D 领导力、六顶思考帽）做成"知识卡片库"，根据学员现场表现**抽取最相关的 10–20 张**讲解，而非一刀切灌输。呈现方式要"活动化"（提问、朗读、讨论），不打断沉浸。
- **戏剧冲突 / 意外卡**：制造 PK、落选者不"出局"而由 CEO 协调安排其他职位；"意外卡"——如讨论陷入瓶颈时 CEO 突然敲门介入，模拟真实变数。
- **AI 作为思考伙伴而非替代**：学员起初把"助攻卡"直接丢给 AI 生成"形式上正确但无落地"的内容——转化为教学契机：先 AI 生成草案，再小组讨论修订，产出"可带回工作的具体方案"。
- **三师节奏**：多位引导师扮演不同节奏的引导者（快慢交替），控制戏剧张力。

## 6. 复盘方法论（灵魂 —— 对应平台 Reflection）

> 没有结构化复盘的体验只是娱乐。复盘把"经历"变成"学习"。

**四步法 / After-Action Review（AAR，美军、行动学习通用）**

| 步 | 问什么 | 要点 |
| --- | --- | --- |
| 1 回顾目标 | 我们想达成什么？ | 回溯初衷，对照实际结果 |
| 2 盘点事件 | 关键亮点/不足是什么？ | 实事求是，不夸大不回避 |
| 3 分析原因 | 为什么？成功因做对什么？失败因什么？ | 审慎质疑"揽功诿过"；主客观都质疑 |
| 4 总结规律/行动 | 学到了什么？下次怎么不同？ | 规律要经质疑；**落到具体、有时限的承诺** |

**通用复盘四问（flux.am / AAR）**：
1. What did we expect?（预期）
2. What happened?（事实）
3. Why the difference?（差异原因）
4. What will we sustain/improve?（持续或改进）

**复盘设计原则（务必遵守）**
- **心理安全**：明确"无评判区"，人人都用了当时最优信息做决定。
- **Ask before tell**：先放大参与者自己的洞察，再给理论；学习才粘得住。
- **证据锚定**：用抉择记录、能力变化、行为标签等"证据物"避免空泛。
- **命名行为，不命名人**：谈"这种行为在真实工作中会怎样"，不评判人。
- **以承诺收尾**：每次复盘结束要有"具体、有时限的下一步行动"；无承诺的复盘=无改变。
- **对成功也要复盘**：只复盘失败=只学避损；复盘成功=可复制的洞察。
- **时长参考**：工作坊中复盘≈场景时长；微场景更短， cohorts 可加深。

> 平台映射：Reflection 阶段 = 把 AAR 四步结构化成离线包里的"复盘手册"；
> Facilitator Console 导出"各组抉择轨迹 + 能力雷达"作为复盘证据物。

## 7. 运营与迭代

- **试讲 → 学员共迭代**：试课阶段邀请学员参与优化选题、互动、奖励规则（某管理沙盘课：1 期试讲 + 2 期落地，满意度 98.4%）。
- **知识卡片库沉淀**：把多门课的理论点沉淀为可复用卡片库，跨剧情框架灵活替换（六顶思考帽/冲突解决/国学领导智慧都能塞进同一剧情）。
- **模块化替换**：按客户成熟度侧重不同工具（初级管理者要流程方法，资深要思维突破）。
- **效果证据**：剧本杀培训被验证能提升参与度与知识转化；某物流复盘课业绩增长 45%，某 AI 赋能课培训效率提升 300%、新人上岗周期缩至 7 天。
