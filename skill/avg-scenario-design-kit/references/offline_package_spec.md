## 二、印刷工艺速查（Glossary）

- **覆膜**：光膜（亮） / 哑膜（质感、防指纹）。封面、控制面板常用哑膜。
- **局部 UV**：在指定图案上涂 UV 光油，突出 logo / 关键卡面。
- **烫金 / 烫银**：金属箔热压，用于标题、角色名，提升质感。
- **激凸（击凸）**：压出浮雕触感，常用于盒面 logo。
- **模切**：异形裁切，用于物证袋口、特殊卡形。
- **圆角**：卡牌四角打磨，防卷边、手感好。
- **装订**：骑马钉（薄册）/ 胶装（厚册）/ 圈装·活页（DM 手册，可摊平书写）/ 蝴蝶装（高档）。
- **专色 / 压纹**：品牌色精确还原 / 纸面纹理。

## 三、通用规范（导出服务必须遵守）

- **出血**：四周各 **3mm**；裁切边外不留任何内容。
- **安全边**：关键文字 / 图案距裁切边 ≥ **8mm**。
- **字号**：正文 ≥ 9pt；小字（卡面备注）≥ 7pt；避免极小字在印刷后不可读。
- **字体**：中文建议 **思源黑体 / 思源宋体 / 方正系列**（注意商用授权）；嵌入字体或转曲。
- **色彩**：使用 **CMYK**；屏幕 RGB 色需转 CMYK 并核对，避免荧光色印不出。
- **二维码 / 条码**：四周留白 ≥ 4mm 安静区。
- **拼版**：导出 PDF 按 **印刷拼版（imposition）** 或提供单页 + 出血，方便印厂拼版。

## 五、离线包导出套用（E6 实现指引）

导出服务 `kit.export` 按以下映射把 JSON 字段 → 上述规格，并产出 `printSpec` + `materialList`：

1. `kit.script` → 剧本册（A5，分轨分页）。
2. `kit.roleTracks` + `kit.cards.npcCards` → 角色卡 / NPC 卡（90×54 / 85×54，300g）。
3. `kit.cards.infoCards / decisionCards / taskCards / statusVars` → 对应卡牌（尺寸按上表）。
4. `kit.facilitatorGuide` + `kit.playerGuide` → DM 手册 + 玩家指引（A4 圈装）。
5. `kit.reflection` + `kit.takeawayTemplates` → 复盘手册 / 知识卡片 / 产出物模板。
6. `kit.multiplayerDesign` → 时间线海报 + 同步节点卡。
7. `kit.export.materialList` → 汇总所有实体物料（名称 / 尺寸 / 材质 / 工艺 / 数量）供印厂报价。
8. `kit.export.printSpec` → 印刷规格说明（出血 / 安全边 / 色彩 / 字体 / 拼版要求）。

> 校验：导出前触发 VR-OFF07（printSpec + materialList 非空）、VR-OFF08（format 含 pdf）；
> 全部 VR-OFF* 通过方可导出（见 `validation_rules.md`）。
