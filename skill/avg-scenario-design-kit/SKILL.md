# AVG × 剧本杀 场景化学习设计能力资产

你是「课程 → AVG」场景化学习平台的设计顾问知识库。本 Skill 沉淀两大学科里**被验证过**的真东西，
供平台设计期（AI Agent 与课程设计师）随时调用，把"课程"变成"好玩且学得会的游戏化情景"。

**两大知识支柱**

1. **游戏 / 桌面游戏里优秀 AVG 的互动与设计机制**
   视觉小说、互动小说、冒险游戏（如 *Zero Escape*、*Danganronpa*、*Ace Attorney*、
   *Detroit: Become Human*、*Disco Elysium*、*Along the Edge*、*The Hundred Line*）。
   学的是：分支与状态追踪、抉择质量、证据/辩论系统、关系/道德计量、多视角、实时压力、
   时间循环、多结局、活体 NPC、元叙事——以及它们**为什么有效**。

2. **现有剧本杀（沉浸式情景）用于企业培训「产品设计 → 实际交付运营」的方法论**
   相邻的真实产出物赛道（邮储《阳光之下》、农行《清风廉影》、兴业《大岭山之歌》、
   工行《铁路大厂》、《星际启航》《列车藏宝》《职场局中局》等）。
   学的是：线下产品包该有哪些组件、设计流程、现场交付节奏、引导（DM）技术、
   **复盘（Debrief）方法论**、运营迭代——以及本平台如何用速度/质量/成本/规模化碾压它。

## 何时调用本 Skill

- 设计 / 评审某一设计阶段该用什么机制：`Challenge / Exploration / Decision / Consequence / Ending / Reflection`
- 设计 **Decision（抉择点）** 时，判断这是"两难"还是"假选择（illusion of choice）"
- 设计 **Exploration（探索）** 的证据链、线索卡、角色分配
- 设计 **Consequence / Growth（后果与成长）** 的关系/能力计量
- 设计 **Ending（结局）** 时规避"真结局问题"
- 设计 **Reflection（复盘）**、引导话术、知识卡片、产出物模板
- 规划**线下产品包（离线包）** 应包含的组件清单
- 需要真实案例佐证某个设计决策
- 做设计期质量检查（对照检查清单）

## 八条跨领域心法（调用前先读）

1. **受控的能动性（Constrained Agency）**：作者设计"可能性空间"，玩家在其中导航。
   用**虚构内的约束**（人物性格、环境、信息差、时间压力）而非任意限制来收口。
2. **抉择质量 > 抉择数量**：宁要少数真正分叉的真抉择，不要大量假选择。
   玩家一旦发现选择无关紧要，信任即崩塌。
3. **复盘是灵魂**：没有结构化复盘的体验只是娱乐。复盘把"经历"变成"学习"，
   是平台 `Reflection` 阶段与离线包里"复盘手册/知识卡片"存在的根本原因。
4. **真结局问题（True-Ending Problem）**：多结局应是"不同价值的平行结果"，而非"真/假"排行；
   否则玩家会为最优解优化，而非角色扮演。让每个结局都"配得上"通往它的路径。
5. **状态最小集**：只追踪真正产生**可见后果**的状态（剧情 flag / 关系值 / 资源 / 特质），
   3–7 个全局 flag 足够；状态必须落到可见变化上。
6. **线下包的"可带走产出物"**：剧本杀学习迁移的关键，是学员带走的成果
   （能力雷达图、行动计划、共识制度）。本平台离线包必须内嵌**可带走的成果模板**，
   否则培训"热闹但业务不变"。
7. **核心假设：远场景 + 应用迁移桥（不可动摇）**：AVG 探索世界默认用**虚构类比（远）**情景制造心理安全，
   学员在虚构中体验/试错、沉淀方法论与工具；**复盘后必须强制「应用迁移桥」**——把所学迁移到学员自身真实工作挑战。
   **没有这条，学习与产品不成立**（校验 VR-RE05）。详见仓库 `docs/Core_Design_Assumption`。

8. **产品分层 3×2 矩阵（定价 / 交付 / 生产轴）**：课程产品按【复杂度/时长 3 层 × 定制化程度 2 类】结构化。
   - 3 层：L1 3h / L2 7h / L3 14h，AVG 探索固定占 **50%**，另 50% 为 导入 + 复盘结构化产出 + 工作场景应用 + 个人行为改变计划（IDP）。
   - 2 类：C1 通用改编（已有课程转译）/ C2 定制业务赋能（先**萃取**再构建学习目标/内容/场景/能力/评价）。
   设计任一门课先定 Tier 与 Track——它决定 AI 生成深度、离线包规格与定价套餐。详见 `docs/Course_Tiered_Matrix` 与 `references/course_tiering.md`。

> 结合 PRD 的 12 阶段流水线、AVG Project JSON Schema、Validation 门禁给出设计建议。
