课程产品分层模型 · 3×2 矩阵

本矩阵把「课程 → AVG 场景化学习产品」按【复杂度/时长】与【定制化程度】两个轴结构化，同时服务三件事：① 产品定价与套餐；② 交付物规格；③ AI 生成深度（生产工时）。它建立在已锁定的核心假设之上：默认【远场景】（虚构类比，如星际探索），且 AVG 探索体验严格占总时长 50%，另外 50% 必须是【导入 + 复盘结构化产出 + 工作场景应用 + 个人行为改变计划】——缺应用迁移桥，产品不成立（VR-RE05）。

一、为什么需要这个矩阵

我们卖的不是「一个 AVG 工具」，而是面向乙方讲师 / 甲方 L&D 的【DIY 设计平台】，最终产出物是与竞品一致的线下产品包。用户带进来的课程差异极大：有的已有成熟课件（情境领导），有的只是一句业务目标（物业经理要做市场拓展）。如果不分层，平台既无法给出清晰的定价套餐，也无法告诉 AI 该生成多深。3×2 矩阵把这种差异变成可配置的产品参数。

  • 定价/套餐轴：让乙方讲师清楚「我这门课该卖哪一档」，让平台订阅/项目制定价有据可依。
  • 交付物轴：每一格对应一套明确的可印刷离线包组件清单与规格（见 offline_package_spec）。
  • 生产轴：告诉 AI Pipeline 该跑到多深、抽取/生成多少节点、校验规则套用哪一子集。

二、两个维度的定义

维度一 · 3 层（Tier）—— 按内容/场景复杂度与系统程度，对应总学习时长

层总时长AVG 探索(50%)系统程度适用对象复杂度标志
L1 轻量切片3 小时1.5h单模块 / 单一能力点一个具体情境的「顿悟」单角色·单决策链·2–3 结局
L2 标准单元7 小时3.5h完整主题 / 2–3 能力点一个主题的系统掌握2–3 角色·3–4 决策节点·多结局·轻状态
L3 深度系列14 小时7h多模块 / 系统能力能力迁移到真实业务多视角·深度分支·状态系统·多轮复盘

三层呈递进：越深，分支/结局/角色/状态越多，复盘与应用落地的权重越高，多人课堂运行越复杂（组数与汇合机制）。

维度二 · 2 类（Track）—— 按定制化程度

类名称输入核心流程交付物特征定价逻辑
C1 通用改编Existing-to-AVG已有成熟课程（PPT + 教材）转译：现有 LGM → 适配 AVG 节点（内容/能力已由原课程定义）标准盒装包（可复制、边际成本低）订阅 / 按门改编费（低客单、高复制）
C2 定制业务赋能Bespoke Enablement业务目标 + 真实案例（无现成课件）从萃取开始：主题建模→关键事件访谈→能力建模→场景挑战→评价设计定制包（含萃取报告 + 能力模型 + 定制场景库 + 评价量表）项目制（高客单、含萃取与设计）
C2 比 C1 多一个【萃取（Extraction）】前置阶段：它不「改编」已有内容，而是先把业务目标和真实事件「萃取」成学习目标、内容、场景挑战、能力要求与水平、评价方式。这是 C2 高价值与高客单的来源。

三、3×2 矩阵总览（六单元格）

C1 通用改编（已有课程）C2 定制业务赋能（从业务目标出发）
L1 轻量切片 (3h)情境领导·单模块切片（如「诊断下属成熟度」）物业经理·单事件切片（如「一次收并购谈判」）
L2 标准单元 (7h)情境领导·完整课（S1–S4 风格匹配 + 两难）物业经理·市场拓展完整赋能（多事件→能力模型）
L3 深度系列 (14h)领导力系列（多模块，多日/系列）物业经理·市场拓展与收并购全业务赋能

四、50 / 50 时间分配模型（核心约束）

无论哪一层，AVG 探索体验固定占总时长 50%；其余 50% 是【非 AVG 工作坊活动】，由四项构成：① 导入（情境铺垫/目标共识）② 复盘结构化产出（AAR + 可带走产出物）③ 工作场景应用（当堂把方法论迁移到真实任务）④ 个人行为改变计划 IDP（30–60 天行为契约）。

非 AVG 50% 的四项活动 · 分层权重（设计建议，可调）

活动（占非 AVG 50%）L1 (1.5h)L2 (3.5h)L3 (7h)随层变化逻辑
① 导入40% (0.6h)25% (0.9h)15% (1.05h)越深越少，前置共识已在前序建立
② 复盘结构化产出35% (0.5h)30% (1.05h)25% (1.75h)始终是高权重，但绝对时长随层放大
③ 工作场景应用15% (0.2h)25% (0.9h)35% (2.45h)越深越偏落地，套真实任务
④ 个人行为改变计划 IDP10% (0.2h)20% (0.7h)25% (1.75h)越深越强调长期行为契约
权重逻辑：浅层快速体验、轻应用；深层强落地——应用与 IDP 占比随层显著上升，导入占比下降。这是「系统程度」递增在时间表上的直接体现。
③ 与 ④ 不可混为一谈：工作场景应用是【当堂】把方法论套到真实业务任务（团队/业务层）；IDP 是个人【30–60 天】的行为契约（个人层）。两者都要有独立模板，且都指向真实场景（满足 VR-RE05 应用迁移桥）。

五、六单元格详述

L1·C1 轻量改编

维度说明
场景复杂度单角色、单决策链、2–3 个平行价值结局；无状态系统或仅 1–2 个 flag。
学习对象与颗粒度一个具体情境的「顿悟」；单一能力点。
多人课堂运行1 讲师带 4–6 组（每组 4–6 人）；引导脚本轻，单线汇合。
交付物形态标准小盒：1 场景卡 + 角色卡 + 复盘卡 + 应用/IDP 单页。
设计/生产工时锚0.5–1 人天（AI 生成为主，专家校验）。
定价锚（建议）¥3K–8K / 门，或订阅内含。
适用案例情境领导·「诊断下属成熟度」切片。

L1·C2 轻量定制

维度说明
场景复杂度同 L1 结构，但场景来自真实业务事件；含微能力模型（1–2 维度）。
学习对象与颗粒度单一业务事件的「做对一次」。
多人课堂运行同 L1；场景为学员真实工作情境的脱敏版。
交付物形态定制小盒 + 萃取单页（事件→能力→应用）。
设计/生产工时锚2–3 人天（含轻萃取）。
定价锚（建议）¥8K–20K。
适用案例物业经理·「一次收并购谈判」切片。

L2·C1 标准单元改编

维度说明
场景复杂度2–3 角色、3–4 决策节点、多结局、轻状态（关系/资源）。
学习对象与颗粒度一个主题的系统掌握（2–3 能力点）。
多人课堂运行1 讲师带 6 组；引导脚本中等，含 1–2 汇合节点。
交付物形态标准盒：多场景卡 + 角色卡套组 + DM 手册 + 复盘手册 + 能力雷达模板。
设计/生产工时锚1–2 人天。
定价锚（建议）¥8K–20K / 门。
适用案例情境领导·完整课（S1–S4 风格匹配 + 两难）。

L2·C2 标准定制赋能

维度说明
场景复杂度3–4 决策节点、多结局、轻状态；场景库来自多业务事件。
学习对象与颗粒度一个业务主题的完整赋能。
多人课堂运行同 L2；含能力达标水平刻度与复盘雷达。
交付物形态定制盒 + 萃取报告 + 能力模型卡 + 定制场景库 + 评价量表。
设计/生产工时锚5–8 人天（含系统萃取）。
定价锚（建议）¥30K–80K。
适用案例物业经理·市场拓展完整赋能（多事件→能力模型）。

L3·C1 深度系列改编

维度说明
场景复杂度多视角、深度分支、状态系统、多结局；信息密度高。
学习对象与颗粒度多模块系统能力，跨情境迁移。
多人课堂运行1 讲师带 6–8 组；多线并行 + 多次汇合，引导脚本深。
交付物形态精装盒：全套（场景册 + 完整角色体系 + DM 手册 + 复盘手册 + 雷达 + IDP 跟踪）。
设计/生产工时锚3–5 人天。
定价锚（建议）¥20K–50K / 门，或订阅高级档。
适用案例领导力系列（多模块，多日/系列课）。

L3·C2 深度定制赋能

维度说明
场景复杂度多视角 + 深度分支 + 状态系统 + 多轮复盘；场景库覆盖业务全链路。
学习对象与颗粒度业务系统能力，可量化改变。
多人课堂运行同 L3；含业务指标挂钩的评价与跟踪机制。
交付物形态定制精装盒 + 完整萃取报告 + 能力模型 + 定制场景库 + 评价量表 + IDP 跟踪表。
设计/生产工时锚10–20 人天（深度萃取 + 多模块）。
定价锚（建议）¥80K–200K+（项目制）。
适用案例物业经理·市场拓展与收并购全业务赋能。

六、盲区补充（主动完善）

  1. 评价体系分层（Evaluation / Rubric）：L1 = 决策质量自评 + 知识确认；L2 = 能力雷达 + 行为承诺；L3 = 行为改变追踪 + 业务指标。复盘「可带走产出物」规格需随层加深。
  2. IDP 与「工作场景应用」的区分（见第四节提示）：前者个人长期契约，后者当堂业务落地，模板独立、不可混。
  3. C2 萃取前置阶段（Extraction）：业务目标→主题建模→关键事件访谈→能力建模→评价设计。这是 C2 独有输入，决定它从「业务目标」而非「现成 PPT」起步。
  4. 能力模型与水平（Proficiency Level）：C2 必须定义能力维度与达标水平（Novice→Proficient），驱动场景挑战难度与雷达刻度；C1 直接复用原课程能力框架。
  5. 多人课堂运行强度（Facilitation）：引导脚本深度、分组机制、汇合节点复杂度随层递增；L3 需「多线并行 + 汇合」设计，离线包须含同步/汇合节点物料。
  6. 迁移桥真实场景来源差异：C1 用行业通用案例（如情境领导「老周两难」）；C2 用客户真实业务场景。VR-RE05 对两类都强制，但来源不同。
  7. 定价 / 商业模式：C1 = 订阅 / 按门改编（标准盒，复制边际低）；C2 = 项目制（含萃取+定制，高客单）。
  8. 交付物清单差异：C1 = 标准 AVG 包；C2 = 额外含萃取报告 + 能力模型卡 + 定制场景库 + 评价量表。
  9. 生产速度 / 成本碾压对照：对照手工剧本杀 1–3 月 / ¥5K–50K，本矩阵各层把单门从数周压缩到0.5–20 人天、价格锚显著低于定制严肃游戏（€30K–80K / VR ¥150K–500K+）。
  10. 数据回流（虽为线下）：复盘产出物（能力雷达、IDP）由学员/讲师带回，可批量回收做课程迭代——这是 C2 的高价值闭环，也是平台相对手工剧本杀的护城河。
  11. 质量门禁分层（Validation Tiering）：L1 可放宽叙事深度/分支数；L3 强制全量 VR 规则；C2 强制萃取 + 能力模型校验（VR-TIER 系列）。

八、待确认 / 可调项（设计假设，需你拍板）

  • 四活动在 50% 内的权重分配（本文为建议值，可按教学理念调整）。
  • 定价锚数字（需按目标市场进一步校准）。
  • L3 是否允许拆成多天 / 系列课（影响离线包分册规格）。
  • C2 萃取由平台 Agent 自动化到什么程度，还是必须专家介入（影响工时与质量门禁）。
  • 是否要为 C2 单独设计一个「萃取工作区」（Extract Workspace）作为 PRD 的新 Epic。
