一、执行摘要

AVG Course Builder 是一个面向培训师的 DIY 设计平台：把一份传统企业培训课程（PPT/PDF/教材/讲师手册），系统地转换成「可探索、可决策、可复盘、可多人运行」的 AVG 类型学习体验，并导出为线下产品包（实体教学材料 + 形式载体），由引导师在真实课堂里运营。

本产品承载的是「设计功能」，不是「线上运营功能」。最终产出物与竞品一样是线下产品包；线上运营（实时多人 SaaS / 在线数据采集 / LMS）不在产品范围。技术壁垒不是大模型，而是「课程知识→学习行为→情境挑战→游戏世界→探索信息→判断决策→行为后果→能力成长→学习复盘」这套转换规则与数据模型。

核心用户是 乙方讲师（培训师 / 课程公司） 与 甲方企业 L&D / 人才发展专家——他们手里有现成课程需要升级成 AVG，或要为自己业务做定制化的小产品。平台让他们自己动手（DIY），系统自动完成 80% 的 AVG 设计生产，专家做最后 20% 创意与质量控制。

价值主张只有一句话：在速度、质量、成本上碾压所有现有竞品——把单门课 AVG 化从「1–3 月 / 数万至数十万代理费」压缩到「小时级 / 订阅摊薄」，且产出形态与线下运营形式完全对齐。

二、市场背景与机会

企业培训大盘仍在增长：全球企业培训支出约 3,945 亿美元（2025）；中国企培市场 2025 约 7,908 亿元（同比 +4.7%，恢复增长）。承载游戏化的严肃游戏赛道 115→335 亿美元（2025→2032，CAGR 16.5%）；游戏化学习 62→178 亿美元（CAGR 23.4%）。

「课程→剧本杀」是已验证的相邻赛道：邮储《阳光之下》廉洁剧本杀、农行《清风廉影》、兴业《大岭山之歌》红色剧本杀、工行《铁路大厂》党建剧本杀均为真实落地；企业定制盒装剧本 ¥5,000–50,000/套 + 现场 DM，单门课生产 1–3 月。这说明「沉浸式角色扮演 + 复盘」的学习需求真实存在、预算真实存在——但供给端极其低效。

空白就在这里：现有玩家全是「人工编剧 + 代理交付」，没有任何一个「软件化的 DIY 设计平台」让培训师把自己的课自动变成 AVG 包。我们填补的就是这个空白。

三、目标用户与角色

角色是谁诉求为何用 DIY 平台
乙方讲师 / 培训师独立培训师、培训机构、课程公司把存量课程升级成 AVG 以差异化、提高客单价自己动手，免去找编剧/代理，速度成本双优
甲方 L&D / 人才发展专家企业大学、TD、业务赋能岗把内部现有课改造；或为某业务做定制化小产品无需采购昂贵定制开发，自助产出可复用
协作设计师（未来）专业游戏/学习设计师在 AI 草稿上做 20% 创意与质控平台提供草稿与质量门禁，专家聚焦创意
平台管理员我们模板、模型、审核、计费和未来市场运营供给端
关键洞察：用户不是「买在线培训系统的企业」，而是「想把自己课程变成 AVG 的个体/小团队」。这是 prosumer（生产者即消费者）市场，不是企业 SaaS 采购市场。

四、用户痛点与需求

  • 慢：手工编剧/代理交付单门课 1–3 月，跟不上业务节奏。
  • 贵：定制严肃游戏 €30K–€80K/模块；国内剧本杀定制 ¥5K–50K/套 + DM，中小培训师用不起。
  • 不可复制：一门课一份剧本，难多班复用、难规模化。
  • 无数据/无质量保障：依赖编剧水平，缺系统化的学习设计校验。
  • 缺 DIY 工具：现有 e-learning 工具（Articulate 等）需教学设计师手工搭，仍不产出线下 AVG 包。
  • 需求本质：培训师要的是「把自己的课，快速、便宜、稳定地变成能线下玩的 AVG」，而不是又一个在线学习系统。

五、竞品格局（重新框定）

竞品分为三类，本产品填补第四类空白：

  • ① 线下产品包生产者：剧本杀培训盒发行/定制（agency）、定制严肃游戏公司、传统培训内容外包、手工/编剧自制——产出形态与我们一致，但全靠人工、慢且贵。
  • ② e-learning 创作工具：Articulate / Twine——能搭分支课，但需专家、且不产出线下 AVG 包。
  • ③ 在线企培 SaaS：北森 / 腾讯乐享 / 云学堂——做在线培训运营，与我们（设计→线下包）不在同一交付层。
  • ④ 本产品（DIY 设计平台）：唯一让培训师把现成课自动变成高质量离线 AVG 包的工具。

六、价值主张与差异化

  • 速度碾压：单门课 ≤ 小时级自动设计（vs 1–3 月代理）。
  • 成本碾压：订阅 / 按产出摊薄（vs ¥5K–50K+/套 代理费）。
  • 质量稳定：转换规则 + Validators + 自动试玩（Game Tester），让非游戏专家也能产出可玩可复盘设计。
  • DIY 赋能：乙方讲师 / 甲方 TD 自助，把现有课程变成 AVG，无需外包。
  • 产出对齐：最终是实体材料 + 形式载体（盒装/卡/手册），与竞品线下运营形式完全一致，但生产范式为软件化、可复制。
技术壁垒不是「大模型」本身，而是沉淀下来的转换规则与数据模型。一旦沉淀，未来甚至不需要自己设计每个 AVG——培训师、课程公司、企业 L&D 把课程丢进去，系统完成 80% 生产。

七、产品形态与最终产出物

平台形态 = 四工作区（理解 / 映射 / 生成 / 导出）的设计工作台。最终交付物 = 一套可运行、可测试、可修改、可导出的 AVG 课程原型，落地为线下产品包，组件覆盖（源自《设计全景图》）：

  • 剧情 / 脚本（对话、分支、结局）
  • 信息卡 / NPC 卡 / 决策卡 / 任务卡 / 状态变量表
  • 角色分轨：5–6 组拿到不同剧本与角色
  • 讲师控制面板 / 玩家界面说明
  • 多人运行设计：公共事件时间线、各组状态与探索记录、信息发放规则、NPC 使用规则、全班同步节点、最终汇合节点
  • 测试报告（AVG Quality Check + Prototype Test Report）
  • 导出格式：可印刷 / 拼版（PDF / Word / InDesign）+ 物料清单与印刷规格

明确不做（V1 及可预见的未来）：实时多人在线运行后端、在线学习数据采集、LMS / 企业培训运营系统。运营由引导师在物理课堂完成。

八、商业模式与定价

  • 面向 prosumer 的订阅 / 按产出计费（非企业席位制）：免费试用 + 按 kit 导出计费 + Pro 订阅（无限生成 / 高级模板 / 协作 / 品牌白标）。
  • 未来市场（供给端网络效应）：培训师在平台产出的 AVG kit 可上架售卖，平台抽成——这会把「乙方讲师」同时变成供给与获客渠道。
  • 定价锚点：以「一门定制剧本杀 ¥5K–50K」为对标，把单门课 AVG 化的边际成本压到订阅内可摊薄，对中小培训师具有碾压级性价比。

九、GTM 路线

  • 第一步（供给撬动）：拿下有存量课程要升级的乙方讲师 / 课程公司——他们痛点最痛、付费意愿最强、且自带内容。
  • 第二步（甲方渗透）：通过标杆讲师案例，渗透企业 L&D / 人才发展专家，做内部课改造与业务赋能小产品。
  • 第三步（市场飞轮）：鼓励讲师上架 kit，形成「更多 kit → 更多买家 → 更多讲师入驻」的网络效应。

十一、风险与对策

  • 产出质量不稳定 → 转换规则 + Validators + Game Tester 自动试玩 + 专家 20% 质控兜底。
  • DIY 门槛 → LGM 自动映射 + 模板化 + 预览试玩，让非游戏专家可用。
  • 版权 / 内容合规 → 课程素材权属确认 + 内容审核 + 未来市场审核机制。
  • 线下运营不可控 → 运营交给引导师（竞品亦然），平台只保证「设计可被正确运营」（讲师控制面板 / 同步节点 / 汇合节点齐全）。
  • 被代理快速模仿 → 护城河是数据模型与模板沉淀，先发+网络效应构筑壁垒。

十二、结论与下一步

市场真实、需求真实、空白明确。方向不是「再做一个在线 AVG 平台」，而是「做一个让培训师把自己课变成 AVG 线下包的 DIY 设计平台」，用速度/质量/成本碾压剧本杀代理与传统定制。下一步：以《新任管理者团队管理》为 V1 Vertical Slice，按 Task Backlog 的 M1–M4 推进，先证明「小时级 + 可印刷离线包 + 质量通过 validators」可成立。
