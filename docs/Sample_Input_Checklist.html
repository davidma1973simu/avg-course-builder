二、示范填写 · 情境领导课程

示范课程：《情境领导®》（Situational Leadership）企业内训——照此格式填你自己的课即可。

① 课程基本信息

情境领导®（Situational Leadership®）企业内训
1 天（6h），4 个模块：①领导风格 ②下属成熟度 ③风格匹配 ④实战演练。本次切片挑模块③「风格匹配」+ 模块④「实战演练」（最"有戏"，直接涉及抉择与复盘）。
新任一线主管、储备干部（管理岗 0–2 年，刚从业务骨干提拔）。
必须有

② 学习目标与能力模型

1. 能按"能力 × 意愿"诊断下属所处成熟度 R1–R4；
2. 能匹配对应领导风格 S1指令 / S2教练 / S3支持 / S4授权；
3. 在真实带人冲突中，能放下"一种风格走天下"的惯性，灵活切换。
教材第 3 章《成熟度诊断》（P41–58）、第 4 章《四风格匹配》（P59–77）。
必须有

③ 学员对象与真实场景背景

学员刚被提拔，常见痛点：①技术骨干升主管后，管不住昔日"老朋友/老同事"；②对高意愿低能力的新人不敢放手、过度指挥；③对低意愿老员工一味授权却失控。场景普遍、情绪强，天然适合角色扮演。
必须有

④ 现有考核与课堂活动

• 考核：课后书面测（成熟度判断选择题）+ 角色扮演评估表；
• 课堂活动：成熟度诊断练习（给案例判 R1–R4）、风格匹配讨论（案例该用 S 几）、双人角色扮演（一人当主管一人当下属，按设定成熟度互动）。
→ 这些正好对应 AVG 的 Decision 节点（选风格）与 Reflection 节点（复盘评估表）。
强烈建议

⑤ 标志性案例 / 真实两难情境

「老周的两难」：老周是销售冠军，新提拔带 5 人团队。手下小赵（高意愿低能力，R2）总出错，老周嫌烦直接替他做（滑向 S1 过度指令）；而老员工阿强（低意愿但因资历傲，近 R3）不服"以前平起平坐现在被管"，老周又不敢管（滑向 S4 过度授权）。
两难：对阿强，是硬管（伤关系）还是顺着（失管控）？——这就是剧本的核心抉择场景。
强烈建议

⑥ "好课"的参照

经典"顿悟时刻"：学员第一次意识到"我之前一直用 S1 命令式对待那个其实已经 R3 的老员工，难怪他摆烂"。引导师话术："先诊断，再领导——别让风格跑在成熟度前面。"可放进 Reflection 的"知识卡片"。
包装边界

⑦ 品牌 / 视觉 / 脱敏要求

可用虚构公司「华晟科技」；人物一律化名；保留"情境领导®"方法原名（属公开方法论，非保密）；视觉走专业冷静蓝灰，避免卡通化（企业培训调性）。
包装边界

⑧ 期望产出形态

剧本杀式 + 轻量分支混合：每组 5–6 人，分饰"新任主管 / 不同成熟度下属 / 观察者"；1 名引导师带 5–6 组同场。关键抉择点（选 S1–S4）走分支，不同选择进入不同团队走向。
验收

⑨ 试点成功标准

能直接用于一期"新任管理者"培训：学员在剧本中做出风格抉择 → 系统记录决策轨迹 → 复盘时生成个人领导风格雷达图 + 行动计划。可打印成离线包（角色卡/线索卡/DM手册/复盘手册）。

教材：情境领导学员手册.pdf（88 页，含前述 P41–77 章节）
