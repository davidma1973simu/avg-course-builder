AVG Course Builder · 开发任务 Backlog（V1）

基于 PRD V1 Vertical Slice（《新任管理者团队管理》端到端跑通）拆解。产品定位：把企业培训课程转换成可探索/决策/复盘/多人运行的 AVG 学习体验的 DIY 设计平台；最终产出线下产品包（实体教学材料+形式载体），由引导师在线下运营。线上运营（实时多人SaaS/在线数据采集/LMS）不在 V1 范围。合计 188 人天，P0(必须) 151 / P1(增强) 37。

一、里程碑路线（4 阶段 / 约 13 周）

阶段周期主题包含Epic目标
M1W1–3基座 · 解析 · 映射E0, E1, E2课程可导入并产出 Learning Gameplay Map（学习内容→游戏机制映射）
M2W4–7生成 · 编辑器E3, E4一键生成 9 阶段 AVG 设计草稿，并可在节点编辑器继续加工
M3W8–10预览 · 导出离线包（⭐红线）E5, E6作者可试玩验证设计；系统导出一套可印刷/可线下运营的完整 AVG 产品包
M4W11–13质量迭代 · 乙方DIY验收E7, E8设计期质量闭环；由真实乙方讲师 DIY 跑通《新任管理者》并验证速度/质量/成本

二、Coding Agent 推荐开工顺序

严格按依赖推进：E0→E1→E2→E3→E4→E5→E6→E7→E8。E2（LGM 学习玩法映射）与 E6（线下包导出） 是两大护城河/红线——前者决定‘课程能否变成好游戏’，后者决定‘能否产出可线下运营的完整产品包’（取代原‘线上多人运行’红线）。E5 是设计期原型预览/试玩，不是部署产品。

E2 · 学习玩法映射 LGM（⭐核心差异点）

E3 · 12 阶段生成 Pipeline + Validators（设计生产）

US3.1 P0 20人天

作为 创作者，我希望 9 个限权 Agent 编排生成 9 阶段 AVG 设计草稿，以便 点‘生成’即得可玩设计初稿，AI 承担 80% 生产。

  • 实现 Capability/Behavior/Challenge/World/NPC/Exploration/Decision/Consequence/Growth/Ending/Reflection 等 Agent（基于规范 system prompt）
  • Pipeline 编排与上下文传递
  • 限权与成本护栏
验收标准：输入 Course+映射→9阶段草稿；端到端《新任管理者》≤小时级。
US3.2 P0 8人天

作为 平台，我希望 Validator 质量门禁（Learning Validator / Runtime Validator 等，设计期校验），以便 自动拦截不合规设计，保证学习有效性。

  • 校验规则：决策≥2合理选项且有trade-off / 探索有分支 / 复盘闭环 / 学习点覆盖 / 六组可运行 / 讲师可管理
  • 不达标打回重生成
  • 质量报告
验收标准：自动拦截不合规产物；生成质量报告。
US3.3 P1 3人天

作为 创作者，我希望 Pipeline 输出一键导入编辑器，以便 生成与编辑无缝衔接。

  • 草稿→编辑器工程转换
  • 差异合并
验收标准：草稿可在编辑器打开。
